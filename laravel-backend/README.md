# Laravel E-Commerce API

Backend REST API for a full-stack mobile e-commerce application built with Laravel.

The API provides authentication, product management, cart operations, checkout, order management, and Chapa payment integration for the React Native mobile application.

## Features

- User registration and login
- Laravel Sanctum authentication
- Product listing and details
- Persistent shopping carts
- Cart quantity management
- Database transactions
- Stock validation
- Concurrent stock protection
- Order creation
- Order history and details
- Chapa payment initialization
- Chapa payment verification
- Payment return handling
- Checkout idempotency
- Transaction references
- Server-side price and stock validation
- User-specific order authorization

## Tech Stack

- PHP
- Laravel
- Laravel Sanctum
- Eloquent ORM
- MySQL
- Chapa API
- REST API
