# React Native E-Commerce App

Mobile frontend for a full-stack e-commerce application built with React Native, Expo, Expo Router, and TypeScript.

The app communicates with a Laravel REST API for authentication, products, cart management, checkout, orders, and Chapa payments.

## Features

- User registration and login
- Persistent authentication with Expo SecureStore
- Product listing
- Product details
- Shopping cart
- Cart quantity updates
- Stock-aware checkout
- Chapa payment integration
- Payment return handling
- Order history
- Order details
- Pull-to-refresh
- Protected application routes
- TypeScript
- Expo Router file-based navigation

## Tech Stack

- React Native
- Expo
- Expo Router
- TypeScript
- Axios
- Expo SecureStore
- Expo Crypto
- React Context API
- Laravel REST API
- Laravel Sanctum
- Chapa
